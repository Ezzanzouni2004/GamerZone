# 🎮 GamerZone

**GamerZone** est une plateforme Laravel pour gérer des tournois de jeux vidéo en ligne, avec gestion des rôles (Admin, Organisateur, Joueur) et accès sécurisé.

## Fonctionnalités

- Gestion CRUD des tournois  
- Inscription des joueurs aux tournois  
- Authentification avec Laravel Breeze  
- Middleware de contrôle d’accès par rôle  
- Interfaces simples en Blade  

## Installation rapide

1. Cloner le repo & installer dépendances  
2. Configurer `.env`  
3. `php artisan migrate --seed`  
4. `php artisan serve`  

## Technologies

PHP 8, Laravel 9, MySQL, Laravel Breeze, Blade
